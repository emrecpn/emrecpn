### Hi, I'm Emre

I build small, practical tools, usually for a problem I ran into myself. I like things that are free to run: static sites, no servers, and everything in the browser.

#### Featured

**[Fluova](https://github.com/emrecpn/fluova)**: free, open-source practice tests in the 2026 format of the TOEFL iBT® test.
I built it after my own exam, when my practice scores turned out to be far from my real ones.
- Adaptive full-length tests, checked automatically against the official 2026 specification before release
- A shared question bank that builds a fresh test in the browser from questions you haven't seen
- Optional on-device Whisper transcription for Speaking, chosen after measuring it against browser speech recognition
- Interface and answer explanations in English, Turkish and Spanish

[Try it](https://emrecpn.github.io/fluova/) · [Add questions to the bank](https://github.com/emrecpn/fluova/blob/main/CONTRIBUTING.md#question-bank)
